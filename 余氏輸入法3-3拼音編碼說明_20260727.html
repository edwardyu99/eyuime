📘 余氏輸入法 3+3 拼音編碼說明

版本：二０二六年七月廿七日

余氏詞庫雙字詞拼音是3+3編碼。在88391雙字詞中，重碼字6085，重碼率6.88%。方案利用三碼簡化、韻母和聲調變化以減少重碼。

🔤 (一) 三碼簡化

  1. 一般情況，取頭三個字母
    例：半 boon → boo，村 cuen → cue，廣 gwong → gwo，歸 gwai → gwa，骨 gwet → gwe，葵 kwai → kwa，困 kwun → kwu
  2. ang、eng、ing、ong、ung 簡化
    改為 ag、eg、ig、og/on、ug
    例：等 dang → dag，病 beng → beg，定 ding → dig，劏 tong → tog，動 dung → dug。
    *第1聲 ong → og，其餘 ong → on。例：劏房(togfon)。 常用字：光kog
  3. uet 簡化為 ut
    例：月 yuet → yut，雪 suet → sut
  4. ch 和 sh 簡化為 c 和 s
    但以下常用字保留 ch/sh 成三碼：茶查cha，長詳che，子chi(情chg)，曹cho，廚chu，沙sha，上常she，使試市shi(成shg)，數sho，信shu。
    *第1聲 eung → eo(ng)。例：昌ceo，將jeo，香heo，相seo，相信(seoshu)
  5. ng- 聲母簡化
    藝、額、暗、眼、咬、外、岳等字的 ng- 省略
    例：藝 ngai → ai，愛 ngoi → oi
    例外：銀 ngan → un，牛偶 ngau → ngu
  6. 香港姓氏及常用字取頭三碼
    例：陳 cha(n)，李 lee，張 che(ung)，黃 won(g)，何 ho，歐 au，周 cho(w)，胡 wu，馬 ma，麥 mak，史 sze，廖 liu，林 lam，白 bak，蔡 tso(i)，鄭 che(ng)，蔣 chi(ang)，朱 chu，崔 chu(i)，鍾 chu(ng)，葉 ip，金 kam，郭國 kwo(k)，關軍君 kwa(n)，施史司 sze，鄧 tan(g)，曾 tsa(ng)，謝 tse，徐 tsu(i)。
    仔 cha(i)，chi 子，記 kee，德 tak，達 tat，青 tsi(ng)，荃 tsu(en)，慈 tsz，任 yam。
    + 本 bue(n)，氣 hee，美 mee，唔 ngr，嘥 sir，嘢 yer

韻母備註

[#1] aa, a 長短音的分別： 余氏輸入法跟隨港式習慣，將長音[啊]aa簡化為a。短音a變為[矮]ai。例如：沙sa，西sai。
[#2] 因[挨]ai變為[矮]ai： 原ai仍可單字與i/ie共用。例：拜bai/bi。為減少重碼，余氏用i/ie：(cjsy字不分調，例: cie猜踩柴，jie齋債寨，sie嘥徙晒)。非cjsy字1聲用i，其餘2-6聲用ie。例：bi拜bie擺敗，di大die歹帶，fi快，gi街gie解介，hi嗨hie鞋孩械，li拉lie瀨，mi買mie賣埋，ni奶nie乃，pi派pie牌排，ti太呔tie泰，wi歪wie淮懷壞。
[#3] am, an, ao, ap, at, ak 長短音的處理： 余氏輸入法跟隨港式習慣，通常am->um，an->en，ao->au，ap->up，at->et。例：三sam心sum，山san身sen，交gao九gau，圾sap十sup，察cat七cet*，八bat不bet*一yet*，*常用字。殺sat/失set，灣患wan/溫運wen，因忍印yen。短音常用字跟隨港式習慣，例：民文man 雲wan 人仁yan，日逸yat。
[#4] 衣(i)音的處理： 單字i/ee可互用。
[#5] 柯(or/oh)： 缺聲母的字拼成or。例：柯or，波bor，播boh。
[#6] 奧(o/ou)： 缺聲母的字拼成ou。例：奧澳ou。
[#7] 烏(uː)、於(u)ː： 余氏合併為(u)。例：胡wu，語yu。
[#8] 碗(un)： 余氏一般用oon，例：goon觀管貫 boon般半胖，moon們滿悶。例外：本bue 門mun 盤pun。 冤(un)： 余氏一般用uen，例：guen捐卷眷 yuen院怨遠願。例外：yoo冤淵 yun元完原員園圓源 yun潤閏。

🎶 (三) 聲調

余氏單字拼音一般不分聲調。但為了減低重碼，余氏3+3組詞方案用了聲調字母a啞h氣e兒u雨z二(2-6聲)。
